### About Me

CS student and software engineer from Slovenia 🇸🇮. Passionate about rockets 🚀 and computers 💻. 

Following SpaceX Starship rocket development and other aerospace technologies that will help humanity expand to the stars ⭐.  

Interested in DevOps, cybersecurity, Linux, and software engineering.  

I enjoy building desktop and web applications. I've built a variety of applications and have experience with different programming languages, frameworks, and software development practices. 

I've worked with Docker and Kubernetes and enjoy learning about application deployment, networking and server infrastructure through hands-on projects. 

Currently deepening my knowledge of Linux and operating systems in general after recently switching from Windows to Ubuntu as my daily driver. 🐧  
Always learning, building, and exploring new technologies! 🤓

🌱 &nbsp;I'm currently learning **Linux, Kubernetes**
